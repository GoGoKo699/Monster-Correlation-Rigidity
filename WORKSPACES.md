# Maintainer workflow

Repository: https://github.com/GoGoKo699/Monster-Correlation-Rigidity

Use a separate branch and a focused pull request for each change. Check existing
branches before starting overlapping work, review the diff, and merge after the
required checks pass. Preserve other contributors' work and avoid force-pushes.

Follow [AGENTS.md](AGENTS.md) for scientific and preservation rules and
[the reproduction guide](docs/REPRODUCIBILITY.md) for validation commands.

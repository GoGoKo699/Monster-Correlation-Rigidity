## Research package, not a manuscript

This package contains the selected quantitative correlation-identification
proof, sharpness and calibration results, the physics-first tutorial path,
finite verification code, attributed source comparisons, and preserved research
history. These notes prepare a future tagged release; they do not create or
announce a tag, DOI, publication, or manuscript.

The criterion is conditional on an exact simple unitary rational C2-cofinite
holomorphic VOA of CFT type, central charge 24, no weight-one states, and actual
fields with the stated properties. Its classification endpoint belongs to
Abe–Lam–Yamada. Neither an experimental device nor all ambient axioms are
identified by three untrusted measurements.

## Changes since the pre-release audit

The calibration routine now uses scale-aware exact root enclosures and returns
an explicit inconclusive result at its work limit. The current verification
entry point separates exact certificates, documentation, historical strict
replay, and bounded portability. Pinned reproduction requirements, current
fingerprints, citation metadata, and a source map accompany the code.

The historical ledgers have visible status banners. Pinned links replace
ambiguous references to unmerged work. The active path retains the approved
Hopf-style native mathematics, Gaberdiel as the primary anchor, and Yamauchi as
the secondary supplement. Original protected notes, archives, and saved reports
remain intact.

## Boundaries to retain in a future release announcement

The code and mathematical checks do not verify imported classifications or
constitute independent human/formal review. Generic variational methods and
exact Ising-pair classification remain attributed to prior work. The square-root
exponent is sharp; the numerical tolerances are sufficient, not claimed optimal.
No practical field-finding algorithm or sample-complexity result is supplied.

Historical floating-point byte replay may fail while the separate bounded
comparison passes; see [reproduction](REPRODUCIBILITY.md). Legacy archive pages
may contain unsupported macros; see [the archive index](ARCHIVE.md). Neither
limitation should be relabeled a successful strict or universal rendering test.
